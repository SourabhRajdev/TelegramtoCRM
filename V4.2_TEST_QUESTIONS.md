# ARIA V4.2 — Test Questions

## PRIORITY TESTS (Test These First)

### ✅ TEST 1: Full Name Search with Fallback
**What to test:** Automatic retry with first name when full name fails

**Questions to ask:**
```
1. "update ravi khanna pipeline stage to contracted"
2. "mark sourabh sharma as qualified"
3. "change ansh mehta status to contacted"
```

**Expected behavior:**
- System searches full name first
- If fails, automatically retries with first name
- Update succeeds
- Response: "Updating [Name] — status to [Status]"

**What you're testing:**
- Fallback search strategy works
- No generic error messages
- Operation completes successfully

---

### ✅ TEST 2: Staff Queries (Person Name Filtering)
**What to test:** Precise filtering - only shows the requested person

**Questions to ask:**
```
1. "what is yash working on"
2. "show me sourabh's tasks"
3. "what is ansh assigned to"
```

**Expected behavior:**
- Shows ONLY the requested person (not everyone who mentions them)
- Response: "1 staff found: [Name] | Tasks: ..."

**What you're testing:**
- Person name filtering is precise
- No false positives (showing people who mention the name in tasks)

---

### ✅ TEST 3: Contextual Error Messages
**What to test:** Clear error messages when search fails

**Questions to ask:**
```
1. "update john smith to contracted"
2. "find michael johnson"
3. "what is robert working on"
```

**Expected behavior:**
- Clear error message with context
- Response: "I couldn't find '[Name]' in the [board] board. Try using just the first name or check the exact spelling."

**What you're testing:**
- No generic "I couldn't find that item" messages
- Error includes person name and board
- Helpful suggestion provided
